# Prefab Plugin 项目文档

## 1. 项目简介

`prefab-plugin` 是一个 Gradle 插件，用于将交叉编译产出的 native 库（`.so` / `.a`）及头文件，按 [Google Prefab](https://google.github.io/prefab/) 规范打包为 AAR 文件，供 Android 项目通过 `prefab` 依赖引入。

**适用场景**：第三方 C/C++ 库（如 lame、ffmpeg 等）经过交叉编译后，需要以 Prefab AAR 形式发布，供下游项目通过 `find_package` 在 CMakeLists.txt 中直接引用。

---

## 2. 项目结构总览

```
prefab-plugin/
├── app/                          # 示例 Android 应用模块（用于本地调试插件）
├── prefab-plugin/                # 插件核心模块
│   └── src/main/java/io/github/byhook/prefab/
│       ├── PrefabGeneratePlugin.kt          # 插件入口，注册 extension + task
│       ├── extension/
│       │   ├── PrefabRootExtension.kt       # 顶层 DSL 配置（generatePrefab 块）
│       │   ├── PrefabModulesExtension.kt    # 单个模块 DSL 配置（module 块）
│       │   ├── PrefabCmakeExtension.kt      # CMake 构建 DSL 配置（cmake 块）
│       │   └── PrefabLibraryType.java       # 库类型常量：ALL / STATIC / SHARED
│       ├── task/
│       │   ├── CmakeBuildTask.kt            # 场景二：执行 CMake 构建
│       │   ├── GenerateModulesTask.kt       # 生成 prefab modules 目录结构
│       │   └── GeneratePrefabTask.kt        # 打包为 AAR 文件
│       ├── json/
│       │   ├── Prefab.kt                    # prefab.json 数据模型
│       │   ├── PrefabAbi.kt                 # abi.json 数据模型
│       │   ├── PrefabModule.kt              # module.json 数据模型
│       │   └── PrefabAndroidData.kt         # module.json 中 android 块数据模型
│       └── utils/
│           └── PrefabUtils.kt               # JSON 序列化 & 库名格式化工具
├── build.gradle.kts               # 根项目构建配置
├── settings.gradle.kts            # 模块声明
├── gradle/libs.versions.toml     # 版本目录（依赖统一管理）
└── jitpack.yml                   # JitPack 发布配置
```

### 核心模块文件职责

| 文件 | 职责 |
|------|------|
| `PrefabGeneratePlugin.kt` | 插件入口，注册 `generatePrefab` 扩展，在 `afterEvaluate` 阶段注册 task 并配置依赖顺序 |
| `PrefabRootExtension.kt` | 顶层 DSL，定义 `sourceLibsDir`、`abiList`、`prefabName` 等全局配置，以及 `module()` / `modules()` / `cmake()` 方法 |
| `PrefabModulesExtension.kt` | 单个库模块的配置：库名、静态/动态、API 版本、头文件子目录等 |
| `PrefabCmakeExtension.kt` | CMake 构建参数：源码目录、NDK 版本、编译选项等 |
| `CmakeBuildTask.kt` | 按 ABI 列表循环调用 CMake 配置 + 构建，收集产物到指定目录 |
| `GenerateModulesTask.kt` | 读取配置，按 Prefab 规范生成 `prefab/modules/<name>/` 下的完整目录和 JSON 文件 |
| `GeneratePrefabTask.kt` | 将 prefab 目录打包为 `<name>-<version>.aar` |

## 3. 场景一：手动模式 — 已有预编译产物

### 3.1 适用场景

用户已通过其他方式完成 native 库的交叉编译（如独立脚本、第三方构建系统），产出了 `libs/` 目录和 `include/` 目录。只需将这些产物打包为 Prefab AAR。

### 3.2 配置项

```kotlin
generatePrefab {
    // === 输入目录 ===
    sourceLibsDir = rootBuildDir.dir("libs")        // 交叉编译生成的库文件目录，内含各 ABI 子目录
    sourceIncsDir = rootBuildDir.dir("include")     // 交叉编译生成的头文件目录

    // === 输出目录 ===
    prefabBuildDir = rootBuildDir.dir("prefab-build")     // 生成 prefab 中间产物的临时目录
    prefabArtifactDir = rootBuildDir.dir("prefab-artifact") // 最终 AAR 文件输出目录

    // === 元信息 ===
    prefabName = "lame"                              // 预构建库名称
    prefabVersion = "3.100.0"                        // 预构建库版本号
    abiList = mutableListOf("arm64-v8a", "armeabi-v7a", "x86_64", "x86")  // 目标 ABI 列表
    manifestFile = layout.projectDirectory.dir("src/main").file("AndroidManifest.xml").asFile

    // === 前置依赖任务 ===
    dependsOn("crossCompileTask")                    // 可选的交叉编译前置任务

    // === 库模块配置 ===
    module("lame.so", false) {                       // 动态库，key 为生成目录名
        libraryName = "libmp3lame"                   // 实际库文件名（不含后缀和 lib 前缀）
        libraryFileName = "libmp3lame.so"            // 源目录中的实际文件名（含后缀）
    }
    module("lame.a", true) {                         // 静态库
        libraryName = "libmp3lame"
        libraryFileName = "libmp3lame.a"
    }
}
```

### 3.3 配置项说明

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `sourceLibsDir` | `Directory` | 是 | 源库文件目录，内含 `<abi>/<libFileName>` 结构的子目录 |
| `sourceIncsDir` | `Directory` | 是 | 源头文件目录 |
| `prefabBuildDir` | `Directory` | 是 | prefab 中间产物的构建目录 |
| `prefabArtifactDir` | `Directory` | 是 | 最终 AAR 文件的输出目录 |
| `prefabName` | `String` | 是 | prefab 库名，对应最终 `prefab.json` 中的 `name` |
| `prefabVersion` | `String` | 是 | prefab 库版本号 |
| `abiList` | `List<String>` | 是 | 支持的 ABI 列表，如 `arm64-v8a`、`x86_64` |
| `manifestFile` | `File` | 是 | 要打包进 AAR 的 AndroidManifest.xml 文件 |
| `dependsOn(taskName)` | 方法 | 否 | 声明前置依赖的 task 名称，可多次调用 |
| `module(libName, libMode, block)` | 方法 | 是 | 声明一个库模块，`libName` 带后缀（`.so`/`.a`），`libMode` 为 `STATIC`/`SHARED`/`ALL` |

**`module` 块内的字段（PrefabModulesExtension）：**

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `libraryName` | `String` | 同 `libName` | 实际库名，会自动补 `lib` 前缀（如 `mp3lame` → `libmp3lame`） |
| `apiVersion` | `Int` | `21` | Android API Level，写入 `abi.json` |
| `ndkVersion` | `Int` | `25` | NDK 版本号，写入 `abi.json` |
| `includeSubDirName` | `String` | `""` | 头文件子目录名。非空时只拷贝 `sourceIncsDir/<name>` 下的头文件 |

### 3.4 任务流

```
[前置 task（由 dependsOn 声明）]
              │
              ▼
    generateModulesTask          ← 生成 prefab/modules/<name>/ 目录结构和 JSON 文件
              │
              ▼
    generatePrefabTask           ← 将 prefab 目录打包为 .aar 文件
```

### 3.5 产物结构

#### 中间产物（prefabBuildDir 目录）

```
prefab-build/
├── prefab/
│   ├── prefab.json              # 顶层描述：name, version, schema_version, dependencies
│   └── modules/
│       └── lame.so/             # 模块目录名 = module() 的 libName 参数
│           ├── module.json      # 模块描述：library_name, export_libraries
│           ├── include/         # 从 sourceIncsDir 拷贝的头文件
│           └── libs/
│               └── android.arm64-v8a/   # 每个 ABI 一个子目录
│                   ├── abi.json         # ABI 元信息
│                   └── libmp3lame.so    # 实际库文件
```

#### 最终产物

```
prefab-artifact/
└── lame-3.100.0.aar            # 将 prefabBuildDir 内容整体打包的 AAR 文件
```

## 4. 场景二：CMake 模式 — 从源码构建

### 4.1 适用场景

用户只有 C/C++ 源码和 CMakeLists.txt，希望插件自动完成 CMake 构建、产物收集、Prefab AAR 打包的全流程。

### 4.2 配置项

此模式下**不需要**手动设置 `sourceLibsDir` 和 `sourceIncsDir`（它们会被 CMake 构建产物自动覆盖）。

```kotlin
generatePrefab {
    // === CMake 构建配置 ===
    cmake {
        sourceDir = rootProject.layout.projectDirectory   // CMakeLists.txt 所在目录
        buildType = "Release"                              // CMake build type
        platform = 21                                      // ANDROID_PLATFORM
        stl = "c++_shared"                                 // ANDROID_STL
        ndkVersion = "27.0.12077973"                       // NDK 版本（不设则自动探测）
        stripSymbols = true                                // 是否用 llvm-strip 去除符号
        arguments = mapOf("ENABLE_FEATURE" to "ON")        // 额外 CMake -D 参数
        includeSubDirs = emptyList()                       // 手动指定头文件子目录
        cmakePath = null                                   // cmake 可执行文件路径（不设则自动探测）
    }

    // === 输出目录 ===
    prefabBuildDir = rootBuildDir.dir("prefab-build")
    prefabArtifactDir = rootBuildDir.dir("prefab-artifact")

    // === 元信息 ===
    prefabName = "lame"
    prefabVersion = "3.100.0"
    abiList = mutableListOf("arm64-v8a", "armeabi-v7a")
    manifestFile = layout.projectDirectory.dir("src/main").file("AndroidManifest.xml").asFile

    // === 前置依赖任务 ===
    dependsOn("setupHeaders")

    // === 库模块（与场景一相同）===
    module("lame.so", false) {
        libraryName = "libmp3lame"
    }
}
```

### 4.3 CMake 配置项说明（PrefabCmakeExtension）

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| `sourceDir` | `Directory` | 必填 | CMakeLists.txt 所在目录 |
| `ndkVersion` | `String?` | `null`（自动探测） | NDK 版本字符串，如 `"27.0.12077973"` |
| `buildType` | `String` | `"Release"` | CMake `CMAKE_BUILD_TYPE` |
| `platform` | `Int` | `21` | Android API Level (`ANDROID_PLATFORM`) |
| `stl` | `String` | `"c++_shared"` | C++ 标准库 (`ANDROID_STL`) |
| `stripSymbols` | `Boolean` | `true` | 构建后是否用 `llvm-strip --strip-all` 去除符号 |
| `arguments` | `Map<String, String>` | `emptyMap()` | 额外 CMake 参数，每个 key-value 拼为 `-Dkey=value` |
| `includeSubDirs` | `List<String>` | `emptyList()` | 头文件子目录列表，为空时默认取 `sourceDir/include/` |
| `headersDir` | `Directory?` | `null` | 显式指定头文件目录，设置后跳过自动发现 |
| `cmakePath` | `String?` | `null`（自动探测） | cmake 可执行文件路径 |

> **NDK 自动探测优先级**：`cmake.ndkVersion` > 环境变量 `ANDROID_NDK_HOME` > `local.properties` 中的 `ndk.dir` > SDK 目录下最高版本 NDK

### 4.4 任务流

```
[前置 task（由 dependsOn 声明）]
              │
              ▼
    cmakeBuildTask
     ├── resolveNdkPath()           # 定位 NDK
     ├── resolveCmakeBinary()       # 定位 CMake 可执行文件
     ├── 按 abiList 循环：           # 每个 ABI 执行一次
     │   ├── cmake configure        # 配置 CMake 项目
     │   ├── cmake --build          # 执行构建
     │   ├── 收集 .so/.a 文件       # 拷贝到 abiLibsDir
     │   └── llvm-strip（可选）     # 去除动态库符号
     └── collectHeaders()           # 收集头文件
              │
              ▼
    generateModulesTask              # 生成 prefab modules 目录结构和 JSON 文件
              │
              ▼
    generatePrefabTask               # 将 prefab 目录打包为 .aar 文件
```

### 4.5 头文件收集策略

1. 如果配置了 `headersDir`，直接拷贝该目录
2. 否则查找 CMake 构建产物 `_deps/<dep>/include/`（FetchContent 等场景自动发现）
3. 否则按 `includeSubDirs` 列表拷贝，列表为空时回退为 `sourceDir/include/`

### 4.6 产物结构与场景一相同

CMake 构建后 `sourceLibsDir` 和 `sourceIncsDir` 被自动指向构建产物目录，后续流程与场景一完全一致。

## 5. JSON 数据模型

插件的产物遵循 [Google Prefab 规范](https://google.github.io/prefab/)，涉及以下 JSON 文件：

### 5.1 prefab.json（Prefab.kt）

| 字段 | 类型 | 说明 |
|------|------|------|
| `schema_version` | `Int` | Schema 版本号，固定为 `2` |
| `name` | `String?` | 库名称，来自 `prefabName` |
| `version` | `String?` | 库版本号，来自 `prefabVersion` |
| `dependencies` | `List<String>` | 依赖的其他 prefab 库名列表 |

### 5.2 module.json（PrefabModule.kt）

| 字段 | 类型 | 说明 |
|------|------|------|
| `library_name` | `String` | 库名 |
| `export_libraries` | `List<String>` | 导出的库列表 |
| `android.library_name` | `String` | Android 平台的库名 |

### 5.3 abi.json（PrefabAbi.kt）

| 字段 | 类型 | 说明 |
|------|------|------|
| `abi` | `String` | ABI 名称，如 `arm64-v8a` |
| `api` | `Int` | Android API Level |
| `ndk` | `Int` | NDK 版本号 |
| `stl` | `String` | C++ 标准库，静态库为 `c++_static`，动态库为 `c++_shared` |
| `static` | `Boolean` | 是否为静态库 |

## 6. 发布 & 依赖配置

### 6.1 JitPack 发布

项目通过 [JitPack](https://jitpack.io) 发布：

- **`jitpack.yml`**：指定 JDK 版本 `openjdk17`
- **`prefab-plugin/gradle.properties`**：定义 `artifact.group`、`artifact.name`、`artifact.version`
- **`prefab-plugin/build.gradle.kts`**：配置 `maven-publish` 和 `java-gradle-plugin`：
  - 插件 ID：`io.github.byhook.prefab`
  - 入口类：`io.github.byhook.prefab.PrefabGeneratePlugin`

### 6.2 消费方配置

**1. 配置 JitPack 仓库**

```kotlin
// settings.gradle.kts
pluginManagement {
    resolutionStrategy {
        eachPlugin {
            if (requested.id.toString() == "io.github.byhook.prefab") {
                useModule("com.github.byhook:prefab-plugin:${requested.version}")
            }
        }
    }
    repositories {
        maven { url = uri("https://jitpack.io") }
        // ...
    }
}
```

**2. 版本目录**

```toml
# gradle/libs.versions.toml
[versions]
prefab = "1.1.1"

[plugins]
byhookPrefab = { id = "io.github.byhook.prefab", version.ref = "prefab" }
```

**3. 应用插件**

```kotlin
// 根目录 build.gradle.kts
plugins {
    alias(libs.plugins.byhookPrefab) apply false
}

// 库模块 build.gradle.kts
plugins {
    id("io.github.byhook.prefab")
}

generatePrefab {
    // ...
}
```
